# Planning index

These files are Sloth's durable project memory. Update them when a product or
architecture decision changes; do not rely on chat history as the source of
truth.

- `context-graph.md` maps goals, constraints, components, data, and dependencies.
- `decision-log.md` records decisions and unresolved design questions.
- `roadmap.md` explains delivery order, milestones, and release gates.
- `issue-backlog.md` contains publish-ready GitHub issue bodies.

The approved PRD remains the product-level source. These documents refine it
where implementation needs more precise contracts.
